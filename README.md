# Grameen Shop - Premium + Permanent Data

Production-ready Node/Express shop using Supabase PostgreSQL for products/orders and Cloudinary for permanent product images.

## Render Environment Variables
- DATABASE_URL = Supabase Session Pooler URI
- CLOUDINARY_CLOUD_NAME
- CLOUDINARY_API_KEY
- CLOUDINARY_API_SECRET
- SESSION_SECRET
- ADMIN_USER
- ADMIN_PASSWORD

Do not commit secrets to GitHub.
